# Task‑05: Automated UI Tests for E‑Commerce Checkout Flow

## 🎯 Objective
Automate the checkout process on the demo e‑commerce site [ShopLane](https://shoplane-by-lassie.netlify.app/) using Selenium.  
The script includes adding items to the cart, filling out checkout forms, and verifying the success message after purchase.

## 🔍 Scope
- Add items to cart
- Navigate to checkout page
- Fill out checkout form (name, email, address, payment)
- Verify success message after purchase
- Validate page transitions and form validation messages

## ⚙️ Tools Used
- Selenium WebDriver
- Python + PyTest
- Documentation in Markdown

## 📂 Deliverables
- TEST_CASES.md → Detailed test cases
- docs/notes.md → Setup and approach
- docs/report.md → Findings summary
- docs/issues.md → Issues encountered
- test_checkout.py → Selenium automation script
